## 快速验证

进入 `代码/sonic`，使用 Python 3.10+：

```powershell
$env:PYTHONPATH = "src"
python examples/demo.py
python -m unittest discover -s tests -v
```

不需要 API Key。演示里的 `completed` 只验证固定文本；真实模型、隔离修复、跨进程效果对账和 RepoFix Verifier 尚未实现。逐项状态见[设计说明的能力表](./设计说明.md#能力状态与代码证据)。

后续维护以 GitHub 最新 `main` 为基准，按[设计说明中的仓库与 Git 约束](./设计说明.md#仓库维护与-git-约束)修改、验证、通过 PR/CI 合入并核对远端。旧分散文档保留在 Git 历史，不把过期 ZIP 作为另一份源码提交。
