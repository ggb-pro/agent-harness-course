# 文档学习地图

这里分成两类：`Harness体系` 讲任何 Agent 都会遇到的工程问题；`sonic设计` 讲我们自己的助手为什么这样设计、现在做到哪一步。不要把面经当成项目设计正文。

## 初学者：沿一条任务学

1. [从零理解 Agent Harness](./Harness体系/从零理解Agent-Harness.md)：十讲，从“模型说修好了”进入，理解循环、状态、工具、恢复、上下文、安全与验收。
2. [运行 sonic 教学内核](../代码/sonic/README.md)：先跑演示与测试，再沿一次事件轨迹读源码。
3. [sonic 的产品目标](./sonic设计/00-产品目标与非目标.md)与[能力状态](./sonic设计/02-能力状态.md)：区分未来想做与当前已经证明的事。

## 有经验的读者：按机制与取舍查

- [Harness 工程教学](./Harness体系/Harness工程教学.md)：比较 Claude Code、DeepSeek Harness、nanobot 的公开设计，并讨论失败边界。
- [sonic 架构与数据流](./sonic设计/01-架构与数据流.md)、[安全与隐私](./sonic设计/03-安全与隐私.md)、[演进路线](./sonic设计/04-演进路线.md)：看内核边界、权衡和验收门禁。
- [设计决策记录](./sonic设计/ADR/README.md)：查看有争议的选择与复审条件。

学习内容与代码通过链接对照；面试自测见独立的[题库](../面经/README.md)。新技术先登记来源、做实验和评测，再决定是否改变 sonic，而不是把“最新”直接写成“更好”。
