# Agent 面经

[TraceForge：问题驱动设计与面试答案](./TraceForge-问题驱动设计与面试答案.md)是设计与面经的唯一正文。它按 Agent 核心链路、Context/Memory、Tool/安全、恢复/并发、评测/发布和现场追问分组，共 48 题；每组先用易懂的任务例子讲设计，再给出资深工程师答案、当前代码差距和验收方法。

维护时记录公开面经的原始链接和日期；应聘者自述只用于发现考点，不作为公司官方题库或频率统计。答案中的框架行为以对应 GitHub 仓库和公开文档核实。涉及本项目的成果必须能指向[代码与测试](../代码/agent-harness-course/)；只有设计、尚未实现的内容明确标为计划。
