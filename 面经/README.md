# Agent 面经：题库与每周变化

面经与 sonic 产品设计分开维护。[现有 48 题](./题库/Agent-Harness-48题.md)按 Agent 核心链路、Context/Memory、Tool/安全、状态/恢复、评测/发布和补充现场追问分组；问题后的“sonic 拷问”只用于说明本仓库的代码证据或尚未实现的差距。产品决定以[sonic 设计](../文档/sonic设计/README.md)为准。

## 怎么读

先用一两句话回答题目，再解释控制流和取舍，最后说最难的失败窗口与验证方法。涉及 sonic 的成果，必须能链接[代码与测试](../代码/sonic/README.md)；规划中的能力明确称为设计，不写成个人项目已实现。

## 每周怎么更新

每周公开来源的新线索先写候选清单：原始链接、发布日期、实际事件日期（能查到时）、来源类型、可信度和与现有题的重复关系。公开应聘者自述只能用于发现考点，不能冒充公司官方题库，也不据此编造频率。答案中的框架机制用项目官方文档或源码核验；不复制受版权保护的大段原文、不绕过付费或私密资料。

人工核对后更新[稳定题库](./题库/Agent-Harness-48题.md)和[ISO 周报](./周报/README.md)。若没有值得新增的内容，周报可以说明“无实质新增”。来源登记格式见[来源索引](./来源索引.md)；纠错需保留原说法、证据与修订日期。
